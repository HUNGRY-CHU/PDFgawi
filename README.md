# PDFgawi

브라우저에서 PDF를 병합하고 페이지를 추출·분할하며, PDF와 이미지 사이를 변환하는 웹앱입니다. PDF 편집에는 pdf-lib, 페이지 미리보기에는 PDF.js를 사용합니다. 파일과 결과는 브라우저 메모리에서 처리하며 서버로 전송하지 않습니다.

## 실행

Node.js 24에서 아래 명령을 실행합니다.

~~~sh
npm ci
npm run dev
~~~

PDF를 선택하거나 파일 영역에 끌어다 놓습니다. 목록의 화살표로 병합 순서를 바꾸고, 파일 이름을 누르면 해당 PDF를 미리 볼 수 있습니다.

- **병합**은 두 개 이상의 PDF를 목록 순서대로 하나의 PDF로 저장합니다.
- **페이지 추출**은 선택한 PDF에서 입력한 순서대로 페이지를 모아 하나의 PDF로 저장합니다. 예를 들어 `4, 1-2`를 입력하면 4, 1, 2페이지 순서가 됩니다.
- **페이지별 분할**은 선택한 PDF를 지정한 페이지나 범위별 PDF로 나눠 ZIP으로 다운로드합니다. `1, 2, 3~5, 6`처럼 입력하면 쉼표로 구분한 항목마다 PDF를 만들어 ZIP으로 저장합니다. `-`와 `~` 모두 범위 구분자로 사용할 수 있습니다. 범위를 비우면 전체 페이지를 한 페이지씩 분할합니다.

- 상단 **PDF를 이미지로** 도구는 선택한 PDF의 지정 페이지를 각각 PNG로 변환합니다. `3, 1~2`처럼 입력 순서를 지정할 수 있고, 비워 두면 전체 페이지를 변환합니다. 변환 결과를 미리 보고 개별 이미지 또는 ZIP으로 다운로드할 수 있습니다. 이미지 해상도는 기본 2배이며 긴 변은 최대 4096픽셀입니다.
- 상단 **이미지를 PDF로** 도구에서 JPG, PNG, WebP 등 브라우저에서 읽을 수 있는 이미지를 선택하거나 끌어다 놓습니다. 목록 항목을 드래그하거나 위·아래 버튼으로 순서를 바꾼 뒤 PDF를 다운로드합니다. 각 이미지는 비율을 유지한 별도 PDF 페이지가 됩니다.

암호화된 PDF는 지원하지 않습니다. 큰 파일은 브라우저 메모리 한계의 영향을 받을 수 있습니다.

## 빌드와 Cloudflare Pages

~~~sh
npm run build
npm run preview
~~~

Cloudflare 대시보드의 **Workers & Pages → Create application → Pages → Import an existing Git repository**에서 이 프로젝트를 가져옵니다.

| 설정 | 값 |
| --- | --- |
| 프로덕션 브랜치 | 실제 기본 브랜치 (예시 `main`) |
| 빌드 명령 | `npm run build` |
| 빌드 출력 디렉터리 | `dist` |
| Node.js | `.node-version`에서 24 지정 |

PDF.js 워커와 렌더링 리소스는 빌드에 포함되어 같은 사이트에서 로드됩니다. [Cloudflare Pages 빌드 설정](https://developers.cloudflare.com/pages/configuration/build-configuration/)
